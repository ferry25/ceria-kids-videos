# Ceria Kids Story — Shorts harian

Proyek Remotion untuk channel YouTube **Ceria Kids Story**: lagu anak animasi tentang kebiasaan baik.

- `RUNBOOK.md` — langkah produksi & upload harian (dibaca oleh tugas terjadwal).
- `topics.json` — antrean topik dan riwayat video yang sudah tayang.
- `src/tooth/` — contoh lengkap video "Lagu Sikat Gigi".
- `scripts/` — sintesis audio dan skrip upload ke YouTube Studio.
- `videos/` — file MP4 yang sudah dirender (diambil YouTube Studio saat upload).
